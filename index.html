Guía de Comandos de Administración
Comandos oficiales para obtener items de protección y gestionar el auditor
1. Comandos de Obtención de Items (/give)
Ejecuta estos comandos en el chat del juego teniendo permisos de Operador (OP):
/give @s aal:claim_marker 64
/give @s deny 64
/give @s recovery_compass 1
2. Asignar Bloques a Administradores Autorizados
/give teoremasine aal:claim_marker 64
/give julioverx aal:claim_marker 64
/give danix2410 aal:claim_marker 64
3. Comparativa entre Tipos de Protección
Tipo de Zona Bloque Requerido Comportamiento de Jugadores Uso Recomendado
Indestructible minecraft:deny Ningún jugador sin OP puede colocar o romper bloques. Spawn, Tiendas del Servidor, Monumentos.
Monitoreada aal:claim_marker Construcción libre, pero cada bloque roto genera un registro de auditoría. Casas de jugadores, Parcelas privadas.
4. Uso de la Brújula de Auditoría para Inspección
1. Sostén la Brújula de Recuperación (recovery_compass) e interactúa en pantalla.
2. Selecciona la Opción 8. Protected Area Block Break Logs.
3. Revisa la lista con el nombre del jugador, bloque destruido, fecha y coordenadas.
4. Usa el comando de teletransporte para la inspección in situ:
/tp @s X Y Z
